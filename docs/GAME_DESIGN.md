# Agaw-Buhay: Survival — Game Design (living doc)
4-player co-op survival horror, locked-down Metro Manila, Philippine folklore enemies.
Vertical slice = Act 1 (3 stages). Full campaign = 4 acts x 3 stages (see core/data.js STAGES).
Core loop: enter zone -> objectives (generators/gates/rescue) -> director-paced pressure -> crescendo -> extraction.
Identity rules:
- Readable enemy silhouettes; every folklore enemy has unique move/attack/counterplay/sound.
- Scarcity: ammo/medkits tiered loot (55/25/15/5), carry-over across stages.
- Horror via darkness, rain, fog, occlusion, audio — not constant visibility.
- Philippine spaces are MECHANICS: flood slows/muffles, jeepneys = cover/loot, courts = horde arenas, balete = supernatural zones.
Survivors: Berto (tank/shotgun), Rhea (medic/burst), Jun-Jun (scout/SMGs), Sarge (heavy/AR).
