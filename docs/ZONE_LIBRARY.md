# Zone Library (Act 1 examples, master doc §15)
1 flooded_side_street: tutorial commons + first Tiyanak cry. Props: tricycles, sari-sari, poles, flood debris.
2 barangay_road: wide arena; first special. Court + chapel + hall landmarks.
3 commercial_strip: scavenging/ambush; breakables dense (pharmacy, pawnshop, eatery).
4 flooded_underpass: low visibility, sound horror, Tiyanak pin encounter.
5 crescendo_holdout: locked gate + generators + barricades; rising horde.
6 skyway_approach: movement combat, wind + rain, abandoned vehicles.
7 manananggal_arena: vertical space; force look up; rooftops + ramps; boss mechanics env-linked.
Each zone entry (target schema): { type, size, encounter, coverDensity, lootBudget, lightProfile, audioProfile, landmark }.
